# product-reconciliation-analysis
End-to-end product reconciliation analysis using Excel Power Query and Power BI to identify data inconsistencies, missing products, price differences, and manufacturer discrepancies across Amazon and Google datasets.
# project overview 
This project focuses on reconciling product data from two different sources — Amazon and Google — to identify inconsistencies and understand the quality of the product information across both sources.

The project was completed using Excel Power Query for data cleaning and transformation and Power BI for analysis and visualization.

The goal was to determine which products matched across both sources and identify issues involving product availability, pricing, manufacturers, and product titles.
# business problem
When product information comes from multiple sources, differences in product names, prices, manufacturers, and product availability can make it difficult to maintain reliable and consistent records.

This project addresses questions such as:

* How many products exist across the two sources?
* How many products are available in both sources?
* Which products are missing from Amazon?
* Which products are missing from Google?
* How many products have matching prices?
* How consistent are manufacturer names?
* How consistent are product titles?
* What are the major reconciliation exceptions?

# Key Insights

The analysis revealed that product data from different sources can contain significant inconsistencies.

Some of the key areas requiring attention were:

* Products missing from one source
* Differences in product prices
* Manufacturer naming inconsistencies
* Differences in product titles
* Records requiring further investigation

The dashboard provides a quick way to identify these issues and prioritize records for review.
